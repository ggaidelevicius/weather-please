# 「Weather Please」ブラウザ拡張機能のプライバシーポリシー

_最終更新日：2026年8月1日_

本ポリシーは、本拡張機能がアクセスするデータ、その利用・保護方法、およびユーザーの選択肢を説明します。

## 1. 収集しない情報

閲覧履歴、訪問サイトの内容、連絡先、ファイル、広告識別子にはアクセスせず、収集もしません。Google アカウントまたは Google カレンダーのデータを受信・保存する当社サーバーはありません。

## 2. 位置情報と第三者サービス

地域の天気を取得するため、端末の緯度・経度を使用します。拒否した場合、拡張機能は動作しません。位置情報は天気と地名の取得のため次のサービスへ直接送信され、各サービスのポリシーが適用されます。

- [Open-Meteo](https://open-meteo.com/en/terms)
- [Nominatim/OpenStreetMap](https://osmfoundation.org/wiki/Privacy_Policy)

Nominatim は座標を地名に変換します（逆ジオコーディング）。位置情報はこれらのリクエストにのみ送信されます。

## 3. Google ユーザーデータとカレンダー連携（任意）

Google アカウントを接続すると、新しいタブに今後の予定を表示できます。Google
OAuth 2.0 と `calendar.events.readonly`
スコープを使用します。天気機能にカレンダー権限は不要です。

<a id="google-user-data-access"></a>

### 3.1 アクセスする Google ユーザーデータ

- 接続アカウントの識別・表示にのみ使う、安定したアカウント ID とメールアドレスまたは名前
- 認証と接続維持に使う OAuth アクセストークンおよび更新トークン
- メインカレンダーの今後3日間の予定（最大10件）：タイトル、説明、開始・終了、終日状態、場所、予定状態、識別子、Google カレンダーの元予定リンク

アクセスは読み取り専用です。予定やカレンダーの作成、編集、削除はできません。

<a id="google-user-data-use"></a>

### 3.2 Google ユーザーデータの利用方法

アカウント情報とトークンは、接続、更新、承認済み読み取りリクエストにのみ使用します。予定データは表示、グループ化、並べ替え、重複排除、および元予定へのリンク提供にのみ使用します。

広告、プロファイリング、信用・適格性判断、または汎用 AI/機械学習モデルの開発、改善、学習には使用しません。

<a id="google-user-data-sharing"></a>

### 3.3 共有、転送、開示

データは Google とブラウザ内の拡張機能との間で直接通信され、当社サーバーには送信されません。第三者、広告主、データブローカー、他のユーザーに販売、貸与、共有、転送、開示せず、人が読むことも許可しません。

<a id="google-user-data-protection"></a>

### 3.4 保存と保護

OAuth 2.0 Authorization Code +
PKCE を使用するため、Google パスワードを受信・保存しません。通信は HTTPS/TLS を使用し、必要な読み取り権限のみ要求します。

予定の詳細はブラウザメモリだけに保持します。トークン、アカウント ID、表示名は、拡張機能のオリジンに隔離されたブラウザのローカルストレージに保存され、ブラウザプロファイルと OS のアクセス制御で保護されます。Google データを分析、診断、ログに含めません。

<a id="google-user-data-retention"></a>

### 3.5 保持と削除

予定は、ページを閉じる/再読み込みする、更新データに置き換わる、または接続を解除するとメモリから破棄されます。トークンとアカウント情報は接続中のみローカルに保持され、解除時に削除されます。拡張機能を削除するとローカル拡張機能ストレージも削除されます。

[Google アカウントの接続](https://myaccount.google.com/connections)からアクセスを取り消すこともできます。当社はサーバーやバックアップに Google データを保存しないため、削除すべきサーバー側コピーはありません。

### 3.6 Google API サービスのユーザーデータポリシー

Google API から受け取る情報の利用と転送は、限定的使用の要件を含む
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)
に従います。

## 4. Microsoft Outlook データ（任意）

Outlook も接続できます。Microsoft と OAuth
2.0 で直接認証し、パスワードは受信・保存しません。読み取り専用で、予定はローカル表示され、トークンは解除時に削除されます。Microsoft 側でもアクセスを取り消せます。[Microsoft プライバシー声明](https://privacy.microsoft.com/privacystatement)が適用されます。

## 5. その他の情報の利用

位置情報は地域の天気と地名の取得にのみ使います。高速表示と設定保持のため、天気、設定、位置キャッシュをローカル保存することがあります。

## 6. ユーザーの選択

位置情報は拒否できますが、その場合は動作しません。カレンダー接続は完全に任意で、いつでも解除できます。

## 7. ポリシーの変更

本ポリシーを更新する場合があります。変更はこのページへの公開時に発効します。
