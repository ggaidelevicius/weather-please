# 「Weather Please」ブラウザー拡張機能のプライバシーポリシー

_最終更新日: 2026年6月12日_

お客様のプライバシーは当社にとって重要です。本ポリシーでは、「Weather
Please」ブラウザー拡張機能が収集する可能性のあるデータとその使用方法について説明します。

## 1. 収集しない情報

「Weather
Please」は**お客様の閲覧履歴に関する個人データを一切収集、保存、送信しません**。IPアドレス、閲覧履歴、個人を特定できる情報にはアクセスしません。

## 2. 位置情報データと第三者サービス

ローカルの天気情報を取得するために、「Weather
Please」はお客様のデバイスの位置情報（緯度・経度）へのアクセスを必要とします。インストール時に位置情報のアクセス許可を求められます。拒否した場合、この拡張機能は動作しません。

お客様の位置情報データは、天気情報を取得し、わかりやすい地名を表示するために第三者サービスに直接送信されます。これらのサービスは独自のプライバシーポリシーに従って運営されています。詳細はこちらをご覧ください:

- [Open-Meteo プライバシーポリシー](https://open-meteo.com/en/terms)
- [Nominatim (OpenStreetMap) プライバシーポリシー](https://osmfoundation.org/wiki/Privacy_Policy)

Nominatim は、お客様の座標を読みやすい地名に変換する（逆ジオコーディング）ために使用されます。「Weather
Please」は、これらのリクエスト以外でお客様の位置情報を保存または転送することはありません。

## 3. カレンダーデータ（任意）

「Weather Please」は、今後の予定を表示するために、任意で Google
Calendar または Microsoft
Outlook アカウントに接続できます。アカウントを接続する場合:

- 認証は、業界標準の OAuth
  2.0 プロトコルを使用して、お客様のブラウザーと Google または Microsoft の間で直接行われます。当社がお客様のパスワードを閲覧または保存することはありません。
- 拡張機能は、今後の予定を一覧表示するために必要な最小限の読み取り専用アクセスのみを要求します。予定の作成、編集、削除はできません。
- 予定データ（タイトル、時刻、場所）はプロバイダーから直接取得され、新しいタブページにローカルで表示されます。当社のサーバーに送信、処理、保存されることはありません。
- サインイントークンはブラウザー内にローカルで保存され、アカウントを切断すると削除されます。
- アカウントは拡張機能の設定からいつでも切断できます。また、Google または Microsoft アカウントのセキュリティ設定から拡張機能のアクセス権を取り消すこともできます。

Google および Microsoft によるデータの取り扱いには、それぞれのプライバシーポリシーが適用されます:

- [Google プライバシーポリシー](https://policies.google.com/privacy)
- [Microsoft プライバシー ステートメント](https://privacy.microsoft.com/privacystatement)

Google API から受け取った情報の「Weather
Please」による使用および転送は、限定使用要件を含む
[Google API サービスのユーザーデータに関するポリシー](https://developers.google.com/terms/api-services-user-data-policy)
に準拠します。

## 4. お客様の情報の使用方法

当社は個人データを収集、保存、共有しません。お客様の位置情報は、第三者のサービスから天気データを取得するためにのみ使用され、カレンダーへのアクセスは新しいタブページに今後の予定を表示するためにのみ使用されます。

## 5. お客様の選択肢

インストール時に位置情報のアクセスを許可するかどうかを選択できます。許可しない場合、この拡張機能は動作しません。「Weather
Please」を使用することで、この要件に同意したものとみなされます。カレンダーの接続は完全に任意であり、接続しなくても拡張機能のすべての機能を利用できます。

## 6. プライバシーポリシーの変更

当社は、本ポリシーを随時更新することがあります。変更は本ページに掲載され、即時に有効となります。
