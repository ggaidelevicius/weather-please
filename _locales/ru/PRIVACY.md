# Политика конфиденциальности расширения «Weather Please»

_Последнее обновление: 1 августа 2026 г._

Здесь описано, к каким данным расширение получает доступ, как использует и
защищает их и какие возможности выбора у вас есть.

## 1. Данные, которые мы не собираем

Расширение не получает и не собирает историю просмотров, содержимое сайтов,
контакты, файлы и рекламные идентификаторы. У нас нет сервера, который получает
или хранит данные вашего аккаунта Google или Google Календаря.

## 2. Геолокация и сторонние сервисы

Для местной погоды используются широта и долгота устройства. Без разрешения
расширение не работает. Местоположение передается напрямую сервисам погоды и
определения названия места, к которым применяются их политики:

- [Open-Meteo](https://open-meteo.com/en/terms)
- [Nominatim/OpenStreetMap](https://osmfoundation.org/wiki/Privacy_Policy)

Nominatim преобразует координаты в название места (обратное геокодирование).
Местоположение передается только для этих запросов.

## 3. Данные пользователя Google и интеграция с календарем (необязательно)

Вы можете подключить Google для отображения событий на новой вкладке.
Используются Google OAuth 2.0 и область `calendar.events.readonly`. Для погоды
календарь не нужен.

<a id="google-user-data-access"></a>

### 3.1 Данные Google, к которым мы получаем доступ

- постоянный идентификатор аккаунта, e-mail или имя — только для идентификации
  подключенного аккаунта;
- токены доступа и обновления OAuth — для аутентификации и поддержания
  подключения;
- до 10 событий основного календаря в ближайшие три дня: название, описание,
  начало и окончание, признак события на весь день, место, статус,
  идентификаторы и ссылка на исходное событие.

Доступ предназначен только для чтения. Создание, изменение и удаление календарей
или событий невозможно.

<a id="google-user-data-use"></a>

### 3.2 Использование данных Google

Данные аккаунта и токены используются только для подключения, обновления
авторизации и разрешенных запросов на чтение. События только отображаются,
группируются, сортируются, очищаются от дублей и снабжаются ссылкой на источник.

Данные Google не используются для рекламы, профилирования, решений о кредите или
праве на услуги, а также для разработки, улучшения или обучения универсальных
моделей ИИ/МО.

<a id="google-user-data-sharing"></a>

### 3.3 Передача и раскрытие

Данные передаются напрямую между Google и расширением в браузере, а не нашим
серверам. Мы не продаем, не сдаем, не передаем и не раскрываем их третьим лицам,
рекламодателям, брокерам данных или другим пользователям и не разрешаем людям
читать их.

<a id="google-user-data-protection"></a>

### 3.4 Хранение и защита

Используется OAuth 2.0 Authorization Code с PKCE, поэтому пароль Google не
принимается и не хранится. Запросы защищены HTTPS/TLS, запрашивается только
необходимое чтение.

События находятся только в памяти браузера. Токены, идентификатор и метка
аккаунта хранятся локально, изолированы источником расширения и защищены
профилем браузера и ОС. Данные Google не попадают в аналитику, диагностику или
журналы.

<a id="google-user-data-retention"></a>

### 3.5 Срок хранения и удаление

События удаляются из памяти при закрытии/перезагрузке страницы, обновлении
данных или отключении аккаунта. Токены и данные аккаунта хранятся локально
только до отключения, после чего удаляются. Удаление расширения удаляет его
локальное хранилище.

Доступ можно отозвать в разделе
[Связи аккаунта Google](https://myaccount.google.com/connections). Мы не храним
Google-данные на серверах или в резервных копиях, поэтому серверных копий для
удаления нет.

### 3.6 Политика пользовательских данных сервисов Google API

Использование данных Google API соответствует
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
включая требования ограниченного использования.

## 4. Данные Microsoft Outlook (необязательно)

Можно подключить Outlook. OAuth 2.0 выполняется напрямую с Microsoft; пароль не
принимается и не хранится. Доступ только для чтения, события показываются
локально, а токены удаляются при отключении. Доступ можно отозвать у Microsoft.
Действует
[Заявление Microsoft о конфиденциальности](https://privacy.microsoft.com/privacystatement).

## 5. Прочие данные

Местоположение используется только для погоды и названия места. Погода,
настройки и кэш местоположения могут храниться локально для быстрой загрузки и
сохранения настроек.

## 6. Ваш выбор

Можно отказать в геолокации, но расширение не будет работать. Подключение
календаря полностью добровольно и может быть отключено в любой момент.

## 7. Изменения

Мы можем обновлять политику. Изменения действуют с момента публикации здесь.
