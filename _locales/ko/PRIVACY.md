# "Weather Please" 브라우저 확장 프로그램 개인정보 보호정책

_최종 업데이트: 2026년 8월 1일_

본 정책은 확장 프로그램이 접근하는 데이터, 그 사용·보호 방법과 사용자의 선택권을
설명합니다.

## 1. 수집하지 않는 정보

확장 프로그램은 검색 기록, 방문한 사이트의 콘텐츠, 연락처, 파일 또는 광고
식별자에 접근하거나 이를 수집하지 않습니다. Google 계정 또는 Google 캘린더
데이터를 수신하거나 저장하는 당사 서버는 없습니다.

## 2. 위치 데이터와 제3자 서비스

지역 날씨를 가져오기 위해 기기의 위도와 경도를 사용합니다. 권한을 거부하면 확장
프로그램이 작동하지 않습니다. 위치는 날씨와 읽기 쉬운 지명을 얻기 위해 다음
서비스로 직접 전송되며 각 서비스의 정책이 적용됩니다.

- [Open-Meteo](https://open-meteo.com/en/terms)
- [Nominatim/OpenStreetMap](https://osmfoundation.org/wiki/Privacy_Policy)

Nominatim은 좌표를 지명으로 변환합니다(역지오코딩). 위치는 이러한 요청에만
전송됩니다.

## 3. Google 사용자 데이터 및 캘린더 연동(선택 사항)

Google 계정을 연결하면 새 탭에 예정된 일정을 표시할 수 있습니다. Google OAuth
2.0과 `calendar.events.readonly` 범위를 사용합니다. 날씨 기능에는 캘린더 권한이
필요하지 않습니다.

<a id="google-user-data-access"></a>

### 3.1 접근하는 Google 사용자 데이터

- 연결 계정을 식별하고 표시하는 데만 사용하는 안정적인 계정 ID와 이메일 주소
  또는 이름
- 요청 인증과 연결 유지에 사용하는 OAuth 액세스 및 새로고침 토큰
- 기본 캘린더의 향후 3일 내 일정 최대 10개: 제목, 설명, 시작·종료, 종일 여부,
  위치, 일정 상태, 식별자 및 Google 캘린더 원본 링크

접근은 읽기 전용입니다. 일정이나 캘린더를 만들거나 수정하거나 삭제할 수
없습니다.

<a id="google-user-data-use"></a>

### 3.2 Google 사용자 데이터 사용 방법

계정 정보와 토큰은 계정 연결, 연결 갱신 및 승인된 읽기 요청에만 사용합니다.
일정은 표시, 그룹화, 정렬, 중복 제거 및 원본 링크 제공에만 사용합니다.

광고, 프로파일링, 신용·자격 결정 또는 범용 AI/머신러닝 모델의 개발, 개선, 학습에
Google 데이터를 사용하지 않습니다.

<a id="google-user-data-sharing"></a>

### 3.3 공유, 이전 및 공개

데이터는 Google과 브라우저의 확장 프로그램 사이에서 직접 전송되며 당사 서버로
전송되지 않습니다. 제3자, 광고주, 데이터 브로커 또는 다른 사용자에게 판매, 임대,
공유, 이전 또는 공개하지 않으며 사람이 읽도록 허용하지 않습니다.

<a id="google-user-data-protection"></a>

### 3.4 저장 및 보호

PKCE가 포함된 OAuth 2.0 Authorization Code 흐름을 사용하므로 Google 비밀번호를
받거나 저장하지 않습니다. 요청은 HTTPS/TLS를 사용하며 필요한 읽기 권한만
요청합니다.

일정 세부정보는 브라우저 메모리에만 보관됩니다. 토큰, 계정 ID 및 레이블은 확장
프로그램 출처로 격리된 브라우저 로컬 저장소에 저장되고 브라우저 프로필과
운영체제 접근 제어로 보호됩니다. Google 데이터는 분석, 진단 또는 앱 로그에
포함되지 않습니다.

<a id="google-user-data-retention"></a>

### 3.5 보유 및 삭제

페이지를 닫거나 새로 고치거나, 새 데이터로 교체하거나, 계정 연결을 해제하면 일정
세부정보가 메모리에서 폐기됩니다. 토큰과 계정 정보는 연결된 동안만 로컬에
보관되며 연결 해제 시 삭제됩니다. 확장 프로그램 제거 시 로컬 확장 저장소도
삭제됩니다.

[Google 계정 연결](https://myaccount.google.com/connections)에서 접근 권한을
철회하여 승인을 무효화할 수도 있습니다. 서버나 서버 백업에 Google 데이터를
보관하지 않으므로 삭제할 서버 사본은 없습니다.

### 3.6 Google API 서비스 사용자 데이터 정책

Google API에서 받은 정보의 사용 및 이전은 제한적 사용 요구사항을 포함한
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)를
준수합니다.

## 4. Microsoft Outlook 데이터(선택 사항)

Outlook도 연결할 수 있습니다. Microsoft와 OAuth 2.0으로 직접 인증하며 비밀번호는
받거나 저장하지 않습니다. 읽기 전용이고 일정은 로컬에 표시되며 연결 해제 시
토큰이 삭제됩니다. Microsoft에서도 권한을 철회할 수 있습니다.
[Microsoft 개인정보처리방침](https://privacy.microsoft.com/privacystatement)이
적용됩니다.

## 5. 기타 정보 사용

위치는 지역 날씨와 지명을 얻는 데만 사용합니다. 빠른 로딩과 환경설정 유지를 위해
날씨, 설정 및 위치 캐시를 로컬에 저장할 수 있습니다.

## 6. 사용자의 선택

위치 권한을 거부할 수 있으나 확장 프로그램은 작동하지 않습니다. 캘린더 연결은
완전히 선택 사항이며 언제든 해제할 수 있습니다.
