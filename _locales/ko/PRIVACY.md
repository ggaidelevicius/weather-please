# "Weather Please" 브라우저 확장 기능 개인정보 보호정책

_최종 업데이트: 2026년 6월 12일_

당사는 사용자의 개인정보를 중요하게 생각합니다. 본 정책은 "Weather Please"
브라우저 확장 기능이 수집할 수 있는 데이터와 그 사용 방법을 설명합니다.

## 1. 수집하지 않는 정보

"Weather Please"는 **사용자의 브라우징 활동과 관련된 어떠한 개인정보도 수집,
저장 또는 전송하지 않습니다**. IP 주소, 검색 기록 또는 개인 식별 정보를 수집하지
않습니다.

## 2. 위치 데이터 및 제3자 서비스

지역 날씨 정보를 제공하려면 "Weather Please"가 사용자의 기기 위치(위도 및
경도)에 접근해야 합니다. 설치 시 위치 액세스 권한을 요청받게 됩니다. 이를
거부하면 확장 기능을 사용할 수 없습니다.

사용자의 위치 데이터는 날씨 정보를 검색하고 읽기 쉬운 위치 이름을 표시하기 위해
제3자 서비스로 직접 전송됩니다. 해당 서비스는 자체 개인정보 보호정책을 따르며,
여기에서 확인할 수 있습니다:

- [Open-Meteo 개인정보 보호정책](https://open-meteo.com/en/terms)
- [Nominatim (OpenStreetMap) 개인정보 보호정책](https://osmfoundation.org/wiki/Privacy_Policy)

Nominatim은 사용자의 좌표를 읽기 쉬운 위치 이름으로 변환(역지오코딩)하는 데
사용됩니다. "Weather Please"는 이러한 요청 이외에 사용자의 위치 데이터를
저장하거나 전송하지 않습니다.

## 3. 캘린더 데이터(선택 사항)

"Weather Please"는 예정된 일정을 표시하기 위해 선택적으로 Google Calendar 또는
Microsoft Outlook 계정에 연결할 수 있습니다. 계정을 연결하는 경우:

- 인증은 업계 표준 OAuth 2.0 프로토콜을 사용하여 사용자의 브라우저와 Google 또는
  Microsoft 간에 직접 이루어집니다. 당사는 사용자의 비밀번호를 보거나 저장하지
  않습니다.
- 확장 기능은 예정된 일정을 나열하는 데 필요한 최소한의 읽기 전용 권한만
  요청합니다. 일정을 생성, 수정 또는 삭제할 수 없습니다.
- 일정 데이터(제목, 시간 및 위치)는 공급자로부터 직접 가져와 새 탭 페이지에
  로컬로 표시됩니다. 해당 데이터는 당사 서버로 전송되거나 당사 서버에서 처리
  또는 저장되지 않습니다.
- 로그인 토큰은 사용자의 브라우저에 로컬로 저장되며 계정 연결을 해제하면
  삭제됩니다.
- 확장 기능 설정에서 언제든지 계정 연결을 해제할 수 있으며, Google 또는
  Microsoft 계정의 보안 설정에서 확장 기능의 접근 권한을 취소할 수도 있습니다.

Google 및 Microsoft의 데이터 처리는 각 회사의 개인정보 보호정책을 따릅니다:

- [Google 개인정보 보호정책](https://policies.google.com/privacy)
- [Microsoft 개인정보 보호정책](https://privacy.microsoft.com/privacystatement)

Google API에서 수신한 정보의 "Weather Please" 사용 및 전송은 제한적 사용 요건을
포함한
[Google API 서비스 사용자 데이터 정책](https://developers.google.com/terms/api-services-user-data-policy)
을 준수합니다.

## 4. 사용자 정보 이용 방법

당사는 개인정보를 수집, 저장 또는 공유하지 않습니다. 사용자의 위치 정보는 오직
제3자 서비스에서 날씨 데이터를 가져오는 데만 사용되며, 캘린더 접근 권한은 새 탭
페이지에 예정된 일정을 표시하는 데만 사용됩니다.

## 5. 사용자의 선택

위치 액세스 권한을 허용할지 여부는 사용자가 결정할 수 있습니다. 허용하지 않으면
확장 기능이 작동하지 않습니다. 캘린더 연결은 전적으로 선택 사항이며 연결하지
않아도 확장 기능은 완전히 작동합니다. "Weather Please"를 사용함으로써 이러한
요건에 동의하는 것으로 간주됩니다.

효력이 발생합니다.
