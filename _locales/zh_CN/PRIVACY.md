# **“Weather Please” 浏览器扩展隐私政策**

_最后更新日期：2026 年 6 月 12 日_

您的隐私对我们至关重要。本政策说明了“Weather
Please”浏览器扩展可能收集的数据类型及其使用方式。

## **1. 我们不收集的信息**

“Weather Please” **不会**
收集、存储或传输与您的浏览活动相关的任何个人数据。我们不会访问、存储或共享 IP 地址、浏览历史或任何可识别个人身份的信息。

## **2. 位置数据与第三方服务**

为了提供本地天气信息，“Weather
Please” 需要访问您的设备地理位置（纬度和经度）。安装时，系统会提示您授权访问位置。如果您拒绝，扩展程序将无法运行。

您的位置信息会直接发送到第三方服务，以获取天气数据并显示易读的位置名称。这些服务有其独立的隐私政策，您可以在以下链接查看：

- [Open-Meteo 隐私政策](https://open-meteo.com/en/terms)
- [Nominatim (OpenStreetMap) 隐私政策](https://osmfoundation.org/wiki/Privacy_Policy)

Nominatim 用于将您的坐标转换为可读的位置名称（反向地理编码）。”Weather
Please”不会存储或传输您的位置信息，除非用于向这些服务发送请求。

## **3. 日历数据（可选）**

“Weather Please”可以选择连接您的 Google Calendar 或 Microsoft
Outlook 账户，以显示您即将到来的事件。如果您选择连接账户：

- 身份验证通过行业标准 OAuth
  2.0 协议直接在您的浏览器与 Google 或 Microsoft 之间进行。我们绝不会查看或存储您的密码。
- 扩展程序仅请求列出即将到来的事件所需的最低只读权限。它无法创建、编辑或删除事件。
- 事件数据（标题、时间和地点）直接从您的服务提供商获取，并仅在您的新标签页上本地显示。这些数据绝不会传输到我们的服务器，也不会由我们的服务器处理或存储。
- 登录令牌存储在您的浏览器本地，并在您断开账户连接时删除。
- 您可以随时在扩展程序的设置中断开账户连接，也可以在 Google 或 Microsoft 账户的安全设置中撤销扩展程序的访问权限。

Google 和 Microsoft 对您数据的处理受其各自隐私政策的约束：

- [Google 隐私政策](https://policies.google.com/privacy)
- [Microsoft 隐私声明](https://privacy.microsoft.com/privacystatement)

“Weather Please”对从 Google API 获取的信息的使用和传输遵守
[Google API 服务用户数据政策](https://developers.google.com/terms/api-services-user-data-policy)，包括有限使用要求。

## **4. 我们如何使用您的信息**

我们 **不会** 收集、存储或共享任何个人数据。您的位置信息 **仅**
用于从第三方天气服务获取天气数据，而日历访问权限 **仅**
用于在您的新标签页上显示即将到来的事件。

## **5. 您的选择**

您可以选择是否允许访问您的位置信息。如果您拒绝，该扩展将无法运行。使用 “Weather
Please” 即表示您同意这些要求。日历连接完全可选，即使不连接日历，扩展程序也能完整运行。

## **6. 隐私政策的变更**

我们可能会不时更新本隐私政策。所有更改将在本页面上公布，并在发布后立即生效。

## **7. 联系我们**

如果您对本隐私政策有任何疑问或建议，请通过
[contact@weather-please.app](mailto:contact@weather-please.app) 联系我们。
